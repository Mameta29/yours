# yoursを試す

公開URL: https://yours-api-110852561536.asia-northeast1.run.app

## 接続せずに試す

Geminiの入力欄に「カタログの商品と価格を教えて」と入力する。Google Cloud上のGeminiが公開カタログを検索し、実商品の価格・在庫を返す。この入口は検索専用で、送金は発生しない。共有の試用回数制限に達した場合は時間をおいて再試行する。

## 本人のwalletから購入する

使用するのは **Polygon Amoy / chain ID 80002**。最新版のPC版MetaMask拡張が必要。test JPYCを300以上と、初回設定用のtest POLを本人walletに用意する。保有済みなら追加の入金は不要。本人の秘密鍵・シードフレーズをyoursへ入力することはない。

1. 「ウォレットを接続」からMetaMaskを選ぶ。必要ならAmoyへの切り替えを確認し、ログイン署名を承認する。これは送金の承認ではない。
2. 「AIを追加する」でGeminiを登録する。AI別・すべてのAIの上限、店舗、期限を設定する。
3. 内容を確認して「ウォレットで承認する」を押す。通常accountの場合は、**この操作からMetaMaskのスマートアカウント設定が始まる**。設定メニューを別途開く必要はない。表示される本人確認は承認する。
4. 初回設定の反映後、委任・予算の署名と2件の登録transactionを確認する。画面で進行状況を案内する。本人のwalletからAIへの資産の移動は不要。
5. 「週次ふりかえりテンプレート」（300 test JPYC）を選び、「この購入を任せる」で商品・数量・金額を確認して署名する。
6. Geminiが承認済みのタスクをUCP/AP2/x402で実行する。ホームの「依頼を受け付け→会計を作成→条件を確認→支払いを確定」で状態を確認する。処理中なら同じ注文で待つ。同じ商品を再購入する操作は不要。
7. 履歴の「注文を開く」から、商品・金額・transaction hashを確認する。確定後は「購入品をダウンロード」で実ファイルを受け取る。注文リンクは購入した本人だけが開ける。APIは成功済みのchain receiptを照合してから支払済みにする。

初回のスマートアカウント設定では、0 POLの自分宛て取引を行う。tokenの送金・approveを含まないが、network feeはかかる。設定完了後の登録も含め、**承認画面が1回だけになるという意味ではない**。[設定と復旧の詳細](design/WALLET-ONBOARDING.md)

## 既存ECの商品を購入する

CHEAP RICE SHOP / HIGH RICE SHOPは、既存ECのAmoy検証店舗。カタログは実ECのAPIから取得する。在庫切れの商品は選択できない。実物の発送は行わない。

1. AIの権限設定で購入を許可する店舗を選ぶ。既存の共有予算の使用済み額は維持する。
2. 店舗の商品を選び、購入するAIと注文確認メールの宛先を入力する。メールの宛先は店舗へ送信し、AIには渡さない。
3. 実ECの予約に対する本人署名と、AIへ当該購入を任せる署名を順に確認する。
4. 注文詳細で「支払済み」と「店舗で注文を受け付けました」を確認する。店舗への通知が途切れた場合も、同じ取引で照合を続ける。再購入は不要。

この接続は配送先・variant・必須追加optionのない商品に対応する。店舗からの`ready`応答は注文受付の状態であり、商品を受け取った証拠とは扱わない。公開ECでの本人購入の確認状況は[実装記録](IMPLEMENTATION.md)を参照。

## 中断した場合

- MetaMaskでキャンセルした場合は、同じAIのカードから再開する。
- 「登録を再開」がある場合、保存済みの条件と成功済みのtransactionを引き継ぐ。署名期限が過ぎた部分だけ新しい署名を求める。
- 再読み込み後も同じwallet・networkに接続済みなら、そのまま再開できる。ロック等で再接続が必要な場合は、ログイン後に入力済みの条件を保って元の画面へ戻る。条件を確認し、チェックを付けて登録を進める。
- スマートアカウント設定の通信が途切れた場合も、**同じブラウザ・同じwallet**で同じボタンを押す。保存したbatch IDを照合する。
- ウォレット設定でエラーになった場合は「エラーの詳細」で処理名・RPC番号・理由を確認する。不明なbatch IDの場合も保存情報を消して再送せず、同じブラウザ・接続先か確認する。
- MetaMaskに確認待ちの画面がある場合は、先にその確認を完了する。処理中にaccountやnetworkを切り替えると登録を停止する。
- 別サービスのsmart-account実装が設定済みの場合、yoursは勝手に置き換えない。別のaccountを使うか、既存の設定を本人が確認する。

## 制御を試す

AIの1回上限を商品価格未満に設定して購入を依頼すると、その注文は本人の追加承認へ戻る。承認は当該注文に限り有効。商品の金額・送金先や同意を変更すると実行できない。

AIカードの一時停止は新しい購入要求を止める。「取り消す」はchain上の権限も失効させる。すでに送信したtransactionを巻き戻す操作ではない。

外部AIを接続する場合は[clientの手順](../examples/external-agent/README.md)を使う。本人が購入時に実行先AIを選び、そのAIが自分の鍵でAP2と支払要求を署名する。
