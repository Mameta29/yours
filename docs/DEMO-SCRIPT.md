# 3分で「任せられる理由」を伝える

**AIに資産を渡さず、本人が決めた範囲で買い物を任せる。条件を超える一件は、LINEで本人へ戻す。**

## 撮影前

- PCでyoursと、既存ECの[CHEAP](https://stg-ec.jpyc-service.com/shops/cheap-rice-shop)を開く。LINEは既存の「JPYC EC (Staging)」。初回連携・ウォレット署名は済ませておく。
- My Geminiの1回上限を **1,000 JPYC**、24時間を5,000 JPYCにする。許可店舗は **CHEAP・HIGHの両方**。共有上限は3,000 / 10,000 JPYCのまま。使用済み予算はリセットしない。
- 通常商品の在庫を確認する。撮影開始時はCHEAP 5kg・400 JPYCが1個、CHEAP 10kgが0個、HIGH 5kg・1,200 JPYCが1個以上必要。2026-10-16 00:44 JSTにCHEAP 5kgを1個へ補充済み、HIGH 5kgは19個。[在庫の確認](evidence/rice-demo-ready.json)。撮り直す場合は、その時点の在庫と残り予算を確認する。
- 初回設定、通知、メール、ウォレットの秘密情報を録画に混ぜない。店舗での注文受付は、実物の配送完了と区別する。

## 説明を正確にする

- LINEに見えるのは実際に完了した処理と、実カタログに基づく短い選択理由。モデルの内部思考を表示しているとは説明しない。
- UCPは商取引の共通インターフェース、AP2は本人同意の証拠、x402は支払連携、Gateはチェーン上の強制。ECとはadapter経由のREST APIで接続しており、ECのDBやMCPへ直接つないでいるわけではない。
- LINEの一件承認は、最初にウォレット署名で結び付けたLINEアカウントからの注文専用postback。新しいLINE LoginやWorld認証の証明ではない。
- 返信・チェーン確定には実時間が必要。動画を編集する場合は「待機時間を短縮」と表示する。保存済みの取引を開く場合は「実行済みの購入記録」と説明する。
- CHEAPの公開LINE購入と未許可店舗への一件承認、HIGHの1,000円上限超過による停止と一件承認後の1,200円購入を確認済み。CHEAPの公開検証時は店舗条件の例外承認を使ったため、通常条件内購入の公開証拠とは区別する。成功しなかった場面を固定表示で置き換えない。
