## 撮影前に確認すること

- 自分のテストwalletで撮影し、既存の残高を確認する。撮影のためだけに同じ購入を繰り返さない。
- MetaMaskの秘密鍵・復元用フレーズ、外部AIのbearer token、メールの宛先は映さない。
- public AmoyとLocal Anvilの証拠を混ぜない。実取引にかかった時間を編集で短縮する場合は、その旨を画面に記す。
- 外部ECは送金確定と店舗の注文受付を両方見せる。受付を実物配送・受け取り完了と表現しない。
- 最終動画のURLはREADMEとハッカソンDashboardへ記載する。現状の検証範囲は[実装記録](IMPLEMENTATION.md)と一致させる。
